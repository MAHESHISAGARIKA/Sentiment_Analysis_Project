# Sentiment Analysis Web App

A machine learning-based web application that analyzes user comments and predicts whether the sentiment is Positive or Negative in real time.

## Features

- Real-time sentiment prediction
- Positive and negative sentiment counters
- Modern responsive user interface
- Comment history with sentiment labels
- Machine Learning model integration
- Flask-based backend

---

## Technologies Used

### Backend
- Python
- Flask

### Machine Learning
- Scikit-learn
- TF-IDF Vectorizer
- Logistic Regression

### Frontend
- HTML
- CSS
- Bootstrap

---
## Machine Learning Workflow

### Text Preprocessing
- Lowercase conversion
- URL removal
- Punctuation removal
- Number removal
- Extra space removal
  
### Feature Extraction
TF-IDF Vectorization

### Model
Logistic Regression Classifier
